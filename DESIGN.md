## Brand & Style

This design system synthesizes the disciplined order of Swiss International Typographic Style with the forward-looking vitality of Web3 cybernetics. Built for a multi-disciplinary Product Builder operating across decentralized protocol engineering, system-level UX/UI, and full-stack software development, the aesthetic rejects superficial "hacker" clichés in favor of architectural precision, functional clarity, and luminous dynamic accents.

### Visual Pillars
- **Disciplined Precision (Swiss Modernism):** Strict spatial grids, uncompromising typographic hierarchies, and unambiguous functional affordances. Every UI component adheres to a structured, reproducible geometry.
- **Cybernetic Luminescence:** Controlled photonic energy—sharp electric blues, deep spectral violets, and concentrated cyber teals—illuminates a substrate of deep void tones. Light acts as an indicator of state and interaction rather than decorative noise.
- **Translucent Depth & Optical Density:** High-clarity frosted surfaces, low-opacity vitreous planes, and sub-pixel edge reflections generate layered context without visual bulk.

### Target Audience & Emotional Impact
The interface targets enterprise Web3 founders, Tier-1 venture partners, protocol architects, and design directors. It projects senior-level architectural authority, flawless technical execution, and an obsession with craftsmanship.

## Colors

The color architecture is built dark-first, anchoring on low-reflectance, high-depth void tones that eliminate eye fatigue while allowing electric spectral frequencies to operate with laser-like focus.

### Surface Canvas Hierarchy
- **Base Canvas (`#090D16`):** The primary void. Used for global application canvas backgrounds and root layout viewports.
- **Surface Elevation 1 (`#0F172A`):** The ground layer for layout partitions, permanent side rails, and macro cards.
- **Surface Elevation 2 (`#1E293B`):** Interactive card planes, active drawers, and elevated contextual panels.
- **Surface Elevation 3 (`#334155`):** Popovers, active state overlays, contextual menus, and floating tooltips.

### Spectral Accents
- **Primary Electric Blue (`#3B82F6`):** Signals principal interactions, primary active navigational nodes, and core Web3 application flows.
- **Secondary Violet (`#8B5CF6`):** Design discipline accent. Applied to UX/UI case study markers, creative technology tags, and gradient terminal stops.
- **Tertiary Cyber Teal (`#14B8A6`):** Protocol and Smart Contract signals. Represents verified state, live nodes, gas optimizations, and on-chain confirmation events.
- **Action Coral (`#F97316`):** High-priority calls-to-action, availability status beacons, and mission-critical touchpoints. Used sparingly to preserve maximum focal gravity.

### Functional Border & Edge Tokens
- **Ghost Boundary:** `rgba(255, 255, 255, 0.08)` for static container boundaries.
- **Active Edge Highlight:** `rgba(59, 130, 246, 0.50)` for focused inputs and active states.
- **Luminescent Accent Border:** Linear gradient of `rgba(59, 130, 246, 0.60)` transitioning to `rgba(139, 92, 246, 0.20)` along structural diagonals.

## Typography

The typographic strategy orchestrates three distinct type engines to construct explicit cognitive divisions between presentation, information, and machine telemetry:

- **Display & Headlines (Plus Jakarta Sans):** Balances geometric Swiss proportions with contemporary digital legibility. Tight letter tracking (`-0.02em` to `-0.03em`) produces confident, authoritative headlines for case studies and architectural overviews.
- **Body Discourse (Inter):** Highly neutral and utilitarian. Inter delivers seamless sustained reading across detailed technical essays, engineering post-mortems, and complex interface copy without competing with technical visual elements.
- **Telemetry, Code & Meta Data (JetBrains Mono):** Monospaced precision for technical metadata, cryptographic hashes, gas values, tech stack taxonomies, metrics, and micro-labels. Capitalized labels in `label-sm` use expanded kerning (`0.06em`) for immediate scannability.

## Layout & Spacing

The structural layout is based on an uncompromising 12-column architectural grid governed by an 8px base rhythm (`space-xs` = 4px sub-grid unit, `space-sm` = 8px, `space-md` = 16px, `space-lg` = 24px, `space-xl` = 40px).

### Grid Configuration
- **Desktop (>= 1280px):** 12 columns, fixed maximum canvas container of `1440px`, `gutter-lg` (32px), `margin-desktop` (56px).
- **Tablet (768px - 1279px):** 8 columns, fluid layout, `gutter` (24px), `margin` (32px).
- **Mobile (< 768px):** 4 columns, fluid layout, `gutter-sm` (16px), `margin-mobile` (20px).

### Alignment Principles
- Technical metrics and case study indices align strictly to the vertical column lines. 
- Section headers carry a monospaced prefix index (e.g., `01 // ARCHITECTURE`) aligned with the primary left border axis.
- Horizontal dividers employ `0.5px` to `1px` translucent hair lines with consistent `space-xl` vertical margins to preserve breathing room between dense engineering specifications.

## Elevation & Depth

Visual hierarchy is constructed through vitreous glassmorphic layering, sub-pixel edge reflections, and localized photonic illumination rather than traditional drop shadows.

### Elevation Tiers
1. **Tier 0 (Substrate Void):** `#090D16` solid canvas. Absorbs all background light.
2. **Tier 1 (Frosted Panels / Base Cards):** `rgba(15, 23, 42, 0.65)` with a backdrop blur of `16px`, bordered by a subtle `1px` stroke of `rgba(255, 255, 255, 0.08)`.
3. **Tier 2 (Interactive Floating Surfaces):** `rgba(30, 41, 59, 0.70)` with backdrop blur of `24px`, bordered by a top-lit gradient stroke (`rgba(255, 255, 255, 0.15)` at top, decaying to `rgba(255, 255, 255, 0.03)` at bottom).
4. **Tier 3 (Modals & Overlays):** `rgba(15, 23, 42, 0.90)` backed by `32px` saturation-boosted blur with an ambient photonic outer halo: `0 0 40px -10px rgba(59, 130, 246, 0.25)`.

### Photonic Edge Glows
Hover and active states use micro-glows concentrated along border boundaries. Instead of wide, muddy drop shadows, use tight, high-intensity blurs: `0 0 16px rgba(59, 130, 246, 0.35)` or `0 0 20px rgba(20, 184, 166, 0.30)` for smart contract terminal components.

## Shapes

The design system uses a strict **Soft (`1`)** shape language. Ultra-rounded pills and excessive organic curves are avoided to maintain Swiss architectural rigor and a precise engineering tone.

- **Micro Components (Tags, Badges, Tooltips):** `0.25rem` (4px). Matches the sharp sub-pixel baseline.
- **Interactive Units (Buttons, Text Inputs, Segmented Controls):** `0.25rem` (4px) or `0.5rem` (8px, `rounded-lg`). Provides tactile definition without softness.
- **Structural Modules (Project Cards, Code Terminals, Modal Viewports):** `0.5rem` (8px) up to `0.75rem` (12px, `rounded-xl`).
- **Gauges & Status Nodes:** Circular markers (50% radius) are reserved strictly for binary status dots (e.g., live RPC connection, availability ping) and system avatars.

## Components

### Buttons
- **Primary CTA (Coral Spark):** Solid `#F97316` background with `#090D16` bold text (`label-md`). Hover state introduces an energetic photonic glow (`0 0 24px rgba(249, 115, 22, 0.40)`). Height: 44px; padding: `0 space-lg`.
- **Secondary (Cyber Glass):** Translucent background `rgba(59, 130, 246, 0.08)`, border `1px solid rgba(59, 130, 246, 0.40)`, text `#3B82F6` (`label-md`). Hover transitions border to full electric blue with subtle surface tint increase.
- **Tertiary / Ghost:** Borderless, `rgba(255, 255, 255, 0.70)` text, with immediate transitions to pure white text and an underlying 1px monospaced underline on focus/hover.

### Badges & Chips
- Monospaced metadata chips using `label-sm`. 
- Padding: `2px space-sm` (2px 8px).
- Appearance: Border `1px solid rgba(255, 255, 255, 0.12)`, background `rgba(15, 23, 42, 0.80)`.
- Variants: Color-coded left-accent indicators (e.g., a 6px diameter pulsing teal circle for Web3 smart contracts, violet for UX research, blue for TypeScript engine).

### Cards (Project & Case Study Modules)
- Structural vitreous substrate: `rgba(15, 23, 42, 0.60)` background, `16px` backdrop filter.
- Dynamic Border: Inactive state uses `1px solid rgba(255, 255, 255, 0.07)`. Hover state activates an electric indigo-to-purple directional linear gradient stroke with `0 12px 32px -8px rgba(0, 0, 0, 0.6)`.
- Internal structure: Rigid separation between header telemetry, project imagery, descriptive body copy, and bottom technology tag clouds.

### Input Fields & Controls
- **Text Inputs:** Background `rgba(9, 13, 22, 0.60)`, border `1px solid rgba(255, 255, 255, 0.12)`, font `Inter` body-md. Focus state utilizes sharp border transition to `#3B82F6` with inner micro-shadow `inset 0 0 8px rgba(59, 130, 246, 0.20)`.
- **Checkboxes & Radios:** Sharp geometric boxes (`roundedness: 1`), border `1.5px solid rgba(255, 255, 255, 0.25)`. Checked state displays a glowing `#14B8A6` cyber teal solid fill with dark void checkmark.

### Bespoke System Components
- **Live Terminal / Code Inspector:** Monospaced window featuring tabbed interface files (`Contract.sol`, `Engine.ts`, `System.css`), custom scrollbars (`4px` width, `#1E293B`), active line highlighting in `rgba(59, 130, 246, 0.10)`, and a live RPC ping indicator.
- **Architecture Metric Display:** Massive numerical counters (`Plus Jakarta Sans` headline-xl) paired with right-aligned stacked JetBrains Mono micro labels (`label-sm`), separated by continuous vertical hairline borders.
